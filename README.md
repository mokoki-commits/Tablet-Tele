# Tablet+Tele

База знаний и скрипты для оптимизации планшетов (удаление bloatware, ускорение).

## Устройства

| Устройство | Прошивка | Каталог |
|---|---|---|
| Nomi C101044 | Android 8.1.0 | [`devices/Nomi_C101044`](devices/Nomi_C101044) |
| Redmi 9C NFC (`angelican`) | MIUI V12.5.3.0.RCSMIXM, Android 11 | [`devices/Redmi_9C_NFC_angelican_V12.5.3.0.RCSMIXM`](devices/Redmi_9C_NFC_angelican_V12.5.3.0.RCSMIXM) |

В каждом каталоге: `README.md` (что проверяли, что сработало, замеры, ограничения),
`debloat.sh` (применение и откат), `logs/` (сырые данные сессии).
