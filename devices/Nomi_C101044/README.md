# Nomi C101044

- **OS:** Android 8.1.0
- **Chipset:** MediaTek

## Особенности
- **Критично:** Система сильно зависит от служб телефонии. Удаление `com.android.phone` или `com.android.providers.telephony` приводит к циклической перезагрузке (bootloop).
- **Браузер:** Рекомендуется использовать **EinkBro** (оптимален для данного устройства).

## Рекомендуемый стек приложений
Для оптимальной работы на этой модели рекомендуется связка из 3 компонентов:
1. **F-Droid**: Портал для установки и обновления софта без Google Play Services.
2. **EinkBro**: Браузер (уже установлен или рекомендуется к установке).
3. **NewPipe**: YouTube-клиент без рекламы.

## Скрипты
- `debloat.sh`: Безопасная очистка (отключает только Bloatware, сохраняя службы связи).
